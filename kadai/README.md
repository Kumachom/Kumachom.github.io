# kadai

プログラミングの課題・練習問題と、その解答を保存する場所です。

## 使い方

1. 言語ごとにフォルダを分けます(例: `javascript/`, `python/`)
2. 課題ごとに `連番-課題名` のフォルダを作ります(例: `001-fizzbuzz/`)
3. フォルダの中に以下を置きます
   - `problem.md` — 課題の内容(問題文、入力・出力の例など)
   - `solution.拡張子` — 自分の解答コード

## 例

`javascript/000-example/` にサンプルを置いています。新しい課題を追加するときはこれをコピーして使ってください。
